## Paleta de cores

| Cor | Hexadecimal | Uso |
|---|---|---|
| Verde Deloitte | `#86BC24` | Acento energético, inovação e progresso |

## Objetivo

Apresentar uma identidade visual minimalista, tecnológica e corporativa, adequada para uso em certificados, apresentações, plataformas internas, banners e materiais institucionais do bootcamp.
